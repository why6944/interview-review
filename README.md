# interview-review — 面试复盘 Skill

一个用于 **Claude Code** 的 skill：把一次面试的**录音转文字（逐字稿）+ 岗位 JD**，自动转成一份结构化的**面试复盘文档**。

## 它能做什么

- ✅ **全量抽取面试官问题**——开场、背景核实、技术问答、实习规划、反问环节，一个不漏
- ✅ **标注追问关系**——每个问题标为 `【新话题】` 或 `【追问·承 Q 几】`，一眼看清"追问链"
- ✅ **逐题四件套复盘**——标签 + 我的回答 + 三档评分 + 标准答案/补强
- ✅ **对照 JD 找差距**——逐条任职要求对比现状，定位短板
- ✅ **落到行动**——按 P0/P1/P2 排优先级，输出"下一轮面试前该补什么"的可执行清单

## 目录结构

```
interview-review/
├── SKILL.md      # skill 主文件（触发条件 + 七步工作流 + 判断规则 + 输出模板）
├── example.md    # 使用示例（虚构数据）
└── README.md     # 本文件
```

## 安装

**用户级（所有项目生效）** —— 推荐：

```bash
mkdir -p ~/.claude/skills/interview-review
cp SKILL.md ~/.claude/skills/interview-review/
```

**项目级（仅当前项目生效）**：

```bash
mkdir -p <你的项目>/.claude/skills/interview-review
cp SKILL.md <你的项目>/.claude/skills/interview-review/
```

## 使用方法

1. 准备好两样输入：**面试录音的转写文本** + **岗位 JD**。
2. 在 Claude Code 里说（任选其一）：

   - 自然语言：`帮我复盘这次面试`
   - 斜杠命令：`/interview-review`

3. 按提示附上逐字稿和 JD，skill 会自动生成复盘文档，默认保存到逐字稿同目录，文件名 `<原文件名>_复盘.md`。

> 完整示例见 [example.md](./example.md)。

## 输出文档结构

生成的复盘文档包含 10 节：

1. 面试基本信息
2. 总体评价（先看结论）
3. 自我介绍复盘
4. 面试官提问脉络总览（时间序 + 追问标记）
5. 技术问答逐题复盘（分类）
6. 表现亮点
7. 短板与知识盲区（P0/P1/P2）
8. 对照 JD 的差距分析
9. 部门与流程信息
10. 后续行动清单

## 隐私注意 ⚠️

复盘文档通常包含**真实姓名、真实面试对话、以及面试官透露的公司内部信息**（团队规模、业务方向、面试流程等）。

- **不要**把含真实信息的复盘文档提交到公开仓库。
- 上传本 skill 时，`SKILL.md`、`README.md`、`example.md` 均为通用方法论 / 虚构示例，**不含任何个人真实信息**，可安全公开。
- 示例数据一律使用虚构候选人（如 `example.md` 中的"李同学"）。
